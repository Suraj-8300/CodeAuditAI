01. Quick Start

CodeAuditAI ships with an executable runner `codeaudit` that automatically handles environment activation, dependency verification, and multi-agent execution.

# 1. Audit any public or private GitHub repository
$ codeaudit audit https://github.com/owner/repository --export-sarif findings.sarif
# 2. Audit a local project directory with markdown report
$ codeaudit audit ./my-codebase --all --export-md audit_report.md
# 3. Launch the Web Review Studio
$ codeaudit web

02. Installation & Download Options

Option A: 1-Line Automatic Installer (Recommended)

curl -sSL https://raw.githubusercontent.com/Suraj-8300/CodeAuditAI/main/install.sh | bash

Option B: Git Clone & Editable Install

git clone https://github.com/Suraj-8300/CodeAuditAI.git
cd CodeAuditAI
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt && pip install -e .

03. Command: codeaudit web

Starts the high-performance FastAPI server and launches the interactive single-page Web Review Studio in your default browser.

$ codeaudit web --port 8000 --reload

04. Command: codeaudit audit

Runs full repository analysis on a local path or remote GitHub URL with automatic cloning and caching.

Flag Type Description
target string GitHub URL or local directory path.
--all flag Audit all source files instead of High-importance only.
--export-md path Save executive markdown scorecard (e.g. audit.md).
--export-sarif path Save OASIS SARIF v2.1.0 findings JSON for GitHub Security.
--provider choice Override LLM provider (google, claude, openai, deepseek).

05. Command: codeaudit snippet

Audit isolated code strings directly in the shell without touching your project directory.

# Audit raw Python snippet for SQL injection
$ codeaudit snippet --lang python "db.execute(f'SELECT * FROM u WHERE id={uid}')"
# Audit C string for buffer overflow
$ codeaudit snippet --lang c "char b[16]; strcpy(b, src);"

06. Command: codeaudit languages

Prints the full Rich terminal matrix of all 25+ supported languages, recognized file extensions, and custom vulnerability rules.

$ codeaudit languages

07. Command: codeaudit projects

Lists and manages all previously audited codebases indexed in the local SQLite database.

# List all indexed projects with file counts and status
$ codeaudit projects
# Delete a project and purge its cached audits
$ codeaudit projects --delete /absolute/path/to/project

08. CI/CD Integration: GitHub Actions

Drop this workflow file into .github/workflows/audit.yml to automatically gate pull requests and post findings directly into your GitHub Security tab. 

name: CodeAuditAI Gate
on: [push, pull_request]

jobs:
  audit:
    runs-on: ubuntu-latest
    permissions:
      security-events: write
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with:
          python-version: "3.11"
      - name: Install CodeAuditAI
        run: |
          pip install git+https://github.com/Suraj-8300/CodeAuditAI.git
      - name: Run Audit
        env:
          GOOGLE_API_KEY: ${{ secrets.GOOGLE_API_KEY }}
        run: |
          codeaudit audit . --all --export-sarif findings.sarif
      - name: Upload SARIF to GitHub Security Tab
        uses: github/codeql-action/upload-sarif@v3
        with:
          sarif_file: findings.sarif
