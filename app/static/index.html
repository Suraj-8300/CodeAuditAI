CodeAuditAI Command-Line Interface

Automate security checks in your terminal, git hooks, and CI/CD pipelines. Generate instant OASIS SARIF v2.1.0 reports, rich colored audit tables, and executive scorecards with zero overhead.

01. Quick Start

CodeAuditAI ships with an executable runner `codeaudit` that automatically handles environment activation, dependency verification, and multi-agent execution.

# 1. Audit any public or private GitHub repository
$ codeaudit audit https://github.com/owner/repository --export-sarif findings.sarif
# 2. Audit a local project directory with markdown report
$ codeaudit audit ./my-codebase --all --export-md audit_report.md
# 3. Launch the Web Review Studio
$ codeaudit web

02. Installation & Download Options

Option A: 1-Line Automatic Installer (Recommended)

curl -sSL https://raw.githubusercontent.com/Suraj-8300/CodeAuditAI/main/install.sh | bash

Option B: Git Clone & Editable Install

git clone https://github.com/Suraj-8300/CodeAuditAI.git
cd CodeAuditAI
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt && pip install -e .

03. Command: codeaudit web

Starts the high-performance FastAPI server and launches the interactive single-page Web Review Studio in your default browser.

$ codeaudit web --port 8000 --reload

04. Command: codeaudit audit

Runs full repository analysis on a local path or remote GitHub URL with automatic cloning and caching.

Flag Type Description
target string GitHub URL (https://github.com/...) or local directory path.
--all flag Audit all indexed source files instead of High-importance only.
--export-md path Save executive markdown scorecard (e.g. audit.md).
--export-sarif path Save OASIS SARIF v2.1.0 output for GitHub Security.

05. Command: codeaudit snippet

Audit standalone code strings or files directly from the command line without creating a project repository.

$ codeaudit snippet --lang c "char b[8]; strcpy(b, input);"
$ codeaudit snippet --file script.py --lang python

06. Command: codeaudit projects

List all indexed codebases, review audited file counts, or delete cached repositories.

$ codeaudit projects
$ codeaudit projects --delete /path/to/project

07. GitHub Actions CI/CD Workflow

Add `.github/workflows/codeaudit.yml` to your repository to automatically run CodeAuditAI on Pull Requests and upload SARIF alerts directly into GitHub Security: 

name: CodeAuditAI Security Gate
on: [push, pull_request]

jobs:
  audit:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with:
          python-version: "3.11"
      - name: Install CodeAuditAI
        run: |
          pip install git+https://github.com/Suraj-8300/CodeAuditAI.git
      - name: Run Audit
        env:
          GOOGLE_API_KEY: ${{ secrets.GOOGLE_API_KEY }}
        run: |
          codeaudit audit . --all --export-sarif findings.sarif
      - name: Upload SARIF to GitHub Security
        uses: github/codeql-action/upload-sarif@v3
        with:
          sarif_file: findings.sarif
